# data/

Generated by the pipeline (not tracked by git):

```
data/
├── processed/<dataset>/            # main.py stage=prepare_data
│   ├── labeled.jsonl               # D_labeled   (30% of filtered train; human labels)
│   ├── unlabeled.jsonl             # D_unlabeled (99% of the 70%; human labels kept for the Human baseline)
│   ├── validation.jsonl            # 1% of the 70% (eval_loss / best checkpoint)
│   ├── test.jsonl                  # filtered test split (GRA prompts)
│   └── stats.json
└── annotated/<dataset>/<weak>/     # main.py stage=annotate / compute_ms_weights
    ├── unlabeled.jsonl             # weak pseudo-labels y+/y-, r_w, C_weak
    ├── stats.json                  # weak label accuracy vs. human, C_weak stats
    └── ms_weights_<strong>.jsonl   # S(x,y+), S(x,y-) teacher-student token KL
```
